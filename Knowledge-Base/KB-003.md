# KB-003: Azure VM Extension Troubleshooting

## Overview

This knowledge base article provides a structured troubleshooting approach for Azure Virtual Machine extensions that fail during installation or deployment.

---

## Common Symptoms

A user may experience one or more of the following symptoms:

- VM extension deployment fails.
- Extension remains in a failed state.
- Configuration task does not complete.
- Extension installation times out.
- Azure Portal shows an extension deployment error.

---

## Troubleshooting Checklist

### 1. Check Virtual Machine Status

Verify that the Azure Virtual Machine is in the **Running** state.

Confirm that the VM is available before troubleshooting the extension.

---

### 2. Check VM Agent Status

VM extensions depend on the Azure VM Agent to communicate with Azure.

Verify that the VM Agent is installed and responding correctly.

---

### 3. Review Extension Status

Open the VM in the Azure Portal and check the **Extensions + applications** section.

Review the extension status and any available error message.

---

### 4. Review Extension Logs

Check the extension logs inside the VM to identify installation or execution errors.

Look for configuration, permission, or communication-related errors.

---

### 5. Retry the Extension

After correcting the underlying issue, retry the extension deployment.

Avoid repeatedly retrying the deployment without checking the original error.

---

## Root Cause Examples

Common causes of VM extension failures include:

- VM Agent is not responding.
- Incorrect extension configuration.
- Extension installation error.
- Insufficient permissions.
- Network connectivity issues.
- Unsupported extension or configuration.

---

## Resolution Approach

Follow these steps in order:

1. Verify the VM status.
2. Check the VM Agent.
3. Review the extension status.
4. Review extension logs.
5. Identify and correct the underlying issue.
6. Retry the extension deployment.
7. Verify the extension status.
8. Document the root cause and resolution.

---

## Best Practices

- Review the extension error before retrying.
- Keep VM Agent updated where appropriate.
- Use supported extension versions.
- Verify configuration values before deployment.
- Monitor extension deployment status after changes.

---

## Verification

After applying a configuration change:

- Confirm the VM Agent is responding.
- Verify that the extension deployment completes successfully.
- Check the extension status in Azure Portal.
- Confirm that the required configuration task has completed.

---

## Conclusion

Azure VM extension failures should be investigated by checking the VM status, VM Agent, extension status, and extension logs.

Identifying the underlying error before retrying the deployment helps resolve extension issues efficiently.
