# KB-004: Azure VM Backup Troubleshooting

## Overview

This article provides a practical checklist for investigating Azure VM backup failures using Azure Backup and Recovery Services Vault.

## Common Symptoms

- Scheduled VM backup fails.
- A new recovery point is not created.
- Backup job shows Failed or Warning status.
- Recently added VM disks are not included in the backup.

## Troubleshooting Checklist

### 1. Check VM Status

Confirm that the VM is running and does not have an active platform or configuration issue.

### 2. Check Backup Job Status

Open the Recovery Services Vault and review the failed backup job. Check the error details and timestamp.

### 3. Verify Backup Configuration

Confirm that the VM is protected by the correct backup policy and that the expected disks are included in the backup configuration.

### 4. Check Recent VM Changes

Look for recently added or modified disks, extensions, or other VM configuration changes that may affect the backup.

### 5. Run Backup Manually

After correcting the configuration, trigger an on-demand backup and monitor the job.

## Root Cause Examples

Common causes include:

- VM disk changes not reflected in the backup configuration.
- Backup configuration issues.
- Temporary snapshot failures.
- Backup job or vault configuration errors.

## Resolution Approach

Identify the failed backup operation, review the error details, check the VM and backup configuration, correct the issue, and run a manual backup to confirm recovery.

## Best Practices

- Regularly monitor backup job status.
- Verify recovery points are being created.
- Review backup configuration after major VM changes.
- Perform periodic restore tests to confirm recoverability.

## Verification

Confirm that the backup job completes successfully and a new recovery point is available in the Recovery Services Vault.

## Conclusion

Azure VM backup issues should be investigated from both the VM and backup configuration sides. Checking the failed job details first usually helps narrow down the problem quickly.
